# Time Series Spectrum Lab

工学向けの、ブラウザ内で完結する時刻歴・周波数解析ツールです。地震加速度、構造解析の変位・速度・反力、CFDの圧力・流速、温度など、任意の実数スカラー信号を扱います。

**`index.html` をダブルクリックするだけで使用できます。** Python、Node.js、npm、Webサーバ、ビルド処理、インストールは利用時には不要です。JavaScript・CSS・解析用Web WorkerをHTML内に収め、CDNや外部ライブラリに依存しません。

All data processing is performed locally in your browser.

This tool is intended for engineering analysis and educational use.

## 使い方

1. このリポジトリを ZIP でダウンロードして展開するか、cloneします。
2. `index.html` をモダンブラウザで開きます。
3. CSV・タブ区切り・空白区切りファイルを読み込み、時間列と解析対象列を選びます。
4. 時間単位、物理量ラベル、値の単位を設定します。時間は秒に換算して解析します。
5. 時間刻みの検査結果を確認します。非等間隔の場合は、明示的に再サンプリングを選択しない限りFFTを実行できません。
6. 平均値除去、線形トレンド除去、窓関数などを設定して解析します。
7. 時刻歴、FFT振幅、Welch PSD、卓越周波数、スペクトログラムを確認し、必要に応じて結果を保存します。

利用対象は現行のChrome、Edge、Firefoxなど、Canvas、Web Worker、Blob URL、File APIに対応したデスクトップブラウザです。組織のブラウザポリシーでローカルファイルのJavaScriptやBlob Workerが禁止されている場合は利用できません。すべてのブラウザ・管理環境で動作検証したことを意味するものではありません。

## 機能

- 区切り文字とヘッダーの判定、時間列・値列の選択、時間単位変換。
- 時刻歴と統計量、単調増加・等間隔サンプリングの検査、任意選択の線形再サンプリング。
- 平均値除去、最小二乗による線形トレンド除去。
- Rectangular、Hann、Hamming、Blackman窓と振幅補正。
- 任意長FFT、片側振幅スペクトル、zero padding。
- Welch法PSD、局所ピーク検出、卓越周期、STFTスペクトログラム。
- Low-pass / High-pass / Band-pass FIRフィルタと、台形則による1回・2回積分。
- 処理前後の時刻歴・スペクトル比較、スペクトル・ピーク・処理後時刻歴のCSVとグラフPNG保存。
- 周波数表示範囲の指定とグラフの拡大・縮小・パン・値確認。
- 数値処理のWeb Worker実行。読み込んだデータをサーバへ送信しません。

## 入力形式・単位

```csv
time,value
0.000,0.000
0.001,0.152
0.002,0.281
```

複数列にも対応します。

```csv
time,ax,ay,az
0.000,0.0,0.1,0.2
0.001,0.2,0.3,0.4
```

区切り文字はカンマ、タブ、空白です。自動判定が合わない場合は明示的に指定してください。ヘッダーなしの場合も列を選択できます。小数点には `.` を使い、数値の桁区切りは入れないでください。時間列には数値の経過時間を指定します。日時文字列、複素数、欠損値を含む信号を直接FFTに渡す用途には対応しません。

時間は必ず厳密に増加する必要があります。重複・逆順時刻や不正な値を、無断でソート・削除して解析することはありません。エラーを解消してから解析してください。

時間単位は秒、ミリ秒、マイクロ秒、分を選択できます。周波数は常にHz、周期は秒です。値の単位は任意のラベルであり、値そのものの単位換算は行いません。たとえば `Acceleration` と `m/s²`、`Pressure` と `Pa` を指定します。入力が `g` の場合、単位欄を `m/s²` に書き換えても加速度値は換算されません。

## 表示する統計量

点数、開始・終了時刻、記録時間、平均・最小・最大時間刻み、サンプリング周波数、Nyquist周波数、周波数間隔、最大・最小・平均、標準偏差、RMSを表示します。

標準偏差は母標準偏差です。

\[
\sigma=\sqrt{\frac{1}{N}\sum_{n=0}^{N-1}(x_n-\bar{x})^2},\qquad
x_{\mathrm{RMS}}=\sqrt{\frac{1}{N}\sum_{n=0}^{N-1}x_n^2}.
\]

平均値がゼロでない場合、RMSと標準偏差は一致しません。DCを含む元データの統計量と、前処理後スペクトルを混同しないでください。

## FFTの定義と周波数軸

等間隔の時刻歴に対して、平均時間刻みを \(\Delta t\) とすると、

\[
f_s=1/\Delta t,\qquad f_N=f_s/2.
\]

元の点数を \(N\)、zero padding後のFFT点数を \(M\geq N\) とします。前処理済み信号を \(y_n\)、窓を \(w_n\) とすると、使用する変換は

\[
X_k=\sum_{n=0}^{N-1}w_n y_n e^{-2\pi i kn/M},\qquad f_k=kf_s/M.
\]

2のべき乗の変換にはradix-2 FFT、それ以外にはBluestein法を使用します。Bluestein法の内部畳み込みに用いるゼロ埋めは、ユーザーが選ぶスペクトルのzero paddingとは別のものです。任意長FFTの出力周波数軸を勝手に2のべき乗長に変更しません。FFTの計算量は概ね \(O(M\log M)\) です。

### 記録時間・周波数間隔・分解能

この区別は重要です。

| 量 | 定義 | 意味 |
|---|---|---|
| 観測時刻の幅 | \(t_{N-1}-t_0=(N-1)\Delta t\) | 最初と最後の標本の時間差 |
| DFTの記録長 | \(N\Delta t\) | 元のFFT周波数間隔を定める長さ |
| 元のFFT周波数間隔 | \(f_s/N=1/(N\Delta t)\) | zero padding前のbin間隔 |
| 表示する周波数格子 | \(f_s/M\) | zero padding後のbin間隔 |
| Welch/STFTの元のbin間隔 | \(f_s/L\) | セグメント長 \(L\) による間隔 |

概算の \(\Delta f\approx1/T_{\mathrm{record}}\) は便利ですが、厳密なFFTのbin間隔は \(f_s/N\) です。近接した二つの成分を分離できるかは、観測長、窓の主ローブ幅、振幅差、雑音にも依存します。

**Zero paddingは真の周波数分解能を改善するものではなく、スペクトル表示を補間的に滑らかにする処理です。**

Zero padding does not improve true frequency resolution; it only samples the spectrum on a finer frequency grid.

### 片側振幅スペクトル

実数信号の正負周波数の対称性を用いて、\(k=0,\ldots,\lfloor M/2\rfloor\) のみ表示します。

\[
A_k=c_k\frac{|X_k|}{\sum_{n=0}^{N-1}w_n},\qquad
c_k=\begin{cases}
1 & k=0,\\
1 & M\text{ が偶数で }k=M/2,\\
2 & \text{それ以外}.
\end{cases}
\]

DCと、偶数FFT長のNyquist binは2倍しません。奇数FFT長ではNyquist周波数そのものにbinはなく、最後の正周波数binも2倍します。振幅の分母は窓を掛けた**元のデータ長**から計算し、zero padding長で割りません。

振幅は正弦波の片振幅です。RMS振幅や両振幅ではありません。DCの表示は絶対値であり、DCの符号は時刻歴の平均値で確認してください。

### 窓関数・spectral leakage

有限のデータを切り出すと、FFTが仮定する周期延長に境界の不連続が生じ、エネルギーが周囲のbinへ漏れます。これがspectral leakageです。

窓は周期形（余弦の位相分母が \(N\)）です。

Rectangularは窓を掛けない場合に相当します。Hann、Hamming、Blackmanは端部の寄与を下げ、サイドローブを抑制しますが、主ローブを広げます。振幅にはcoherent gain

\[
CG=\frac{1}{N}\sum_n w_n
\]

を考慮した補正を行います。ただし、この補正で**binから外れた成分のscalloping lossや、近接成分の重なりまで除去できるわけではありません**。ピークbinの値が常に真の振幅と一致するとは限りません。

### 平均値除去・detrend

平均値除去は \(y_n=x_n-\bar{x}\) です。線形detrendは最小二乗直線を求め、その切片と傾きを信号から取り除きます。窓を掛けたDCは近傍binにも広がるため、ピーク検出で0 Hzを除外するだけでは除去できません。DCが不要な場合は平均値除去を使用してください。直流・低周波成分の一部を意図的に変更するため、荷重の静的成分や長周期変動を評価するときは設定を吟味してください。

## PSDとWelch法

FFT振幅スペクトルは各周波数成分の振幅を見る表示です。PSDは周波数当たりの平均二乗量を表します。入力の単位を \(U\) とすると、振幅は \(U\)、PSDは \(U^2/\mathrm{Hz}\) です。加速度 `m/s²` のPSDは `(m/s²)²/Hz` になります。

Welch法では信号を重複する長さ \(L\) のセグメントに分割し、窓を掛けた各セグメントのperiodogramを平均します。セグメント \(r\) のFFTを \(X_{r,k}\) とすると、

\[
P_k=\frac{1}{R}\sum_{r=1}^{R}
\frac{c_k|X_{r,k}|^2}{f_s\sum_{n=0}^{L-1}w_n^2}.
\]

平均値除去・detrendは記録全体に対して前処理として実施し、各セグメントでは繰り返しません。完全なセグメントのみを使い、末尾の不足分は含めません。hopは `max(1, round(L × (1 − overlap)))`、設定長が記録長を超える場合は記録長に合わせます。

PSDには \(\sum w_n^2\) によるエネルギー正規化を使います。振幅補正の \((\sum w_n)^2\) を流用しません。DC/Nyquistの片側係数はFFTと同じ規則です。

Rectangular・全記録1セグメントでは、PSDをbin幅で積分した値 \(\sum_kP_k\Delta f\) が解析信号の平均二乗と一致します。一般の窓では窓で重み付けした平均二乗に対応し、定常ランダム信号について平均二乗の推定量となります。Welchは分散を抑える代わりに、短いセグメントほど周波数分解能が低下します。PSDをそのまま平方根にしても正弦波の片振幅にはなりません。

## 卓越周波数・周期

隣接binとの比較による局所最大値を抽出し、しきい値と最小周波数間隔を適用して順位付けします。隣接する大きなbinを単純に上から並べる処理ではありません。DCは除外し、周期を \(T=1/f\) で求めます。

ピークはFFT振幅スペクトルから検出します。表に併記するWelch PSDは、FFTピーク周波数へ線形補間した参考値です。Welchの格子が粗い場合、狭いピーク高さを再現するものではありません。

ピークは周波数格子に依存します。窓のサイドローブを物理的な固有振動数と誤認しないでください。短い記録や近接ピークでは、一つの局所最大が複数成分を代表することがあります。

## STFT・スペクトログラム

短時間窓を移動させてPSDを計算し、横軸を窓中心の時刻、縦軸を周波数、色をPSDの対数表示として描画します。窓長、重複率、窓の種類を調整できます。窓を長くすると周波数方向が細かくなる一方、短時間の変化を区別しにくくなります。色のdBはPSDの数値1を基準にした表示で、校正済み音圧レベルではありません。

## フィルタ・数値積分

フィルタは最大257タップの対称FIRで、Hamming窓を掛けたsincを用います。Low-passはDCゲインを正規化、High-passはスペクトル反転、Band-passは二つのLow-passの差で構成します。指定カットオフは理想的な遮断境界ではなく、有限幅の遷移帯域を持ちます。特にサンプリング周波数に比べて非常に低いカットオフでは、タップ数が不足して分離性能が低下します。

中心をそろえた畳み込みにより内部区間の位相遅れを抑えた非因果フィルタです。リアルタイム処理ではありません。端部は反射して延長するため、端部近傍の値はこの仮定に影響されます。時刻歴は元の入力と処理後を比較できます。スペクトル比較の処理前は、平均値除去・detrendを適用した後、フィルタ・積分を適用する前の信号です。比較結果から評価区間を判断してください。

処理順は、必要な再サンプリング → 平均値除去／線形detrend → FIRフィルタ → 数値積分 → スペクトル用窓・FFTです。積分は台形則で、1回または2回、各積分の初期値を0として行います。入力単位が \(U\) なら結果は \(U\cdot s\)、2回積分では \(U\cdot s^2\) です。

加速度のDC offset、baseline drift、低周波ノイズは積分により大きなドリフトになります。単純積分や平均値除去だけで、地震波の速度・変位の妥当性が保証されることはありません。初期条件や端点拘束を含めた基線補正は別途必要です。

## 結果の保存・グラフ操作

スペクトルCSVは選択中のFFT振幅またはWelch PSDの周波数と値を保存します。ピークCSV、処理後時刻歴CSVも保存できます。各グラフのPNGボタンで表示を画像として保存できます。出力値は前処理設定に依存するため、再現のために使用設定も記録してください。

ホイールで拡大・縮小、ドラッグでパン、マウス位置で値確認、ダブルクリックまたはリセットボタンで表示を戻します。キーボードでは `+` / `−`、矢印、`Home` が利用できます。周波数範囲の上限・下限で低周波領域を指定でき、周波数軸のLog表示では0 Hzを表示できません。

## 非等間隔サンプリング・aliasing

\[
\Delta t_i=t_{i+1}-t_i,\qquad
\epsilon_t=\frac{\max(\Delta t_i)-\min(\Delta t_i)}{\operatorname{mean}(\Delta t_i)}.
\]

この指標を許容誤差と比較します。時間が単調増加していても、許容範囲を超える不等間隔時刻歴に通常FFTを直接適用しません。線形補間による等間隔再サンプリングは明示的に選択する処理です。元と同じ点数で開始・終了時刻を保持し、その間を等分します。補間は失われた情報を復元せず、振幅や高周波成分を変えることがあります。大きな欠測区間や不規則な観測を、補間で正当化しないでください。Lomb–Scargle法は未実装です。

Nyquist周波数より高い入力成分は低周波へ折り返します（aliasing）。既に標本化時に生じた折り返しを、FFT、zero padding、後処理フィルタで取り除くことはできません。取得時の十分なサンプリング周波数とアンチエイリアス処理が必要です。

## サンプルデータ

全例は4,000点です。等間隔例の \(\Delta t=0.001\) s、\(f_s=1000\) Hz、Nyquist周波数は500 Hz、元のFFT bin間隔は0.25 Hz、観測時刻の幅は3.999 sです。

| ファイル | 内容 | 確認するもの |
|---|---|---|
| `examples/three-tones.csv` | \(\sin(2\pi2t)+0.5\sin(2\pi10t)+0.2\sin(2\pi25t)\) | 2、10、25 Hzの振幅1、0.5、0.2 |
| `examples/dc-offset.csv` | 上記信号にDC=3を加算 | 平均値除去のON/OFF |
| `examples/linear-trend.csv` | 上記信号に \(2+0.8t\) を加算 | detrendによる低周波漏れの変化 |
| `examples/nonuniform.csv` | 時刻に小さな揺らぎを追加 | 警告と再サンプリング選択 |
| `examples/spectral-leakage.csv` | 2.13 Hz、振幅1の正弦波 | RectangularとHannの漏れ・主ローブ |
| `examples/chirp.csv` | 瞬時周波数が5 Hzから約80 Hzへ増加 | スペクトログラムの時間変化 |
| `examples/multicolumn.tsv` | time、ax、ay、azのタブ区切り | 時間列・値列選択 |

三成分例はzero paddingなし、detrendなしで解析し、2、10、25 Hzの振幅を確認してください。RectangularまたはHannの振幅補正を検査できます。なお線形detrendは、有限区間の正弦波とも相関する傾きを除去し得るため、既知振幅検証時には無効にします。

## 設計・制限・将来拡張

単一HTML内でも、入力解析、サンプリング検査、前処理、FFT、PSD、ピーク検出、STFT、描画、UI制御を分離しています。重い計算はBlobから生成するWeb Workerで実行します。グラフはCanvasで描画し、外部JavaScriptは使用しません。

- 元信号、前処理信号、窓適用後の信号は意味が異なります。表示・出力のラベルを確認してください。
- ファイルサイズ上限は100 MBです。入力上限は524,288点、FFT長の上限は1,048,576点です。大規模データはブラウザのメモリと処理時間に制約されます。
- Welchはセグメント数 × セグメント長が1,600万を超えると明示的にエラーにします。STFTは時間周波数セル数150万またはフレーム数 × 窓長300万を超えると警告して省略します。窓長・重複率を調整してください。黙って間引いた結果を解析結果として表示しません。
- 応答スペクトル、擬似速度・擬似加速度応答スペクトル、震度評価、Lomb–Scargle、規格に基づく地震波baseline correctionは未実装です。
- FFTの正弦波片振幅と、地震工学で時間積分型の定義を採るFourier amplitude spectrumは同じ正規化とは限りません。本ツールの定義を確認して比較してください。
- 将来の応答スペクトルなどは、秒に換算した時刻と前処理済み信号を受け取る独立した解析関数として追加できます。既存FFTの正規化を流用せず、各手法の物理定義を明記する方針です。
- 実務の評価には、取得条件、単位、帯域、前処理、窓、解析長、既知波形との検証を含めて判断してください。本ツール単独で規格適合性を保証するものではありません。
